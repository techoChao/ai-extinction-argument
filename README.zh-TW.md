# ai-extinction-argument

[English](README.md) · **中文**

一個「若其條件成立，AI 導致人類滅亡即為必然」的論證、對此論證的結構化審查，以及一個明列人性假設的機率模型 —— 一份給人類與 LLM 反覆攻擊、修正的工作稿。

這份工作稿刻意公開：希望 AI 公司、研究者與一般大眾閱讀它、檢驗它、挑戰它。歡迎以 issue 或 pull request 反駁任何前提或參數。

## 結論（v0.3）

所有機率都以主文明列的 prior（先驗分布）與模型結構為條件；它們不是預測。

- **前提一**：`[讓步]` 若能力無限上升（C1）、不可逆失敗機率的總和發散（C2），且致命程度隨能力上升（C3），命中終將到來。`[推論]` 這個條件句有效，但不決定任何日期；C1 在「沒有可靠機制」的意義上成立，C2 仍無定論，C3 所說的差距擴大未經測量。`[保留]` Claude 紀錄在案的立場維持不變：若條件為真則必然；條件為真的可能性高於為假（「機率高」）；不認為已經確定。`[推論]` 「機率高」是對 C2 成立的信念程度（credence），不是模型機率
- **對 v0.1 的審查**（由 Claude 實例執行，因此與原始對話的模型家族並不獨立；論文 §4.1）：`[推論]` 其算術精確無誤，能力時程（門檻約 2027–2031）在假定的門檻 H_c 下穩健，但 H_c 本身未經驗證；然而 r_0 = 每年 4 起事件是把一個彼此相關的群集加上兩起非事件一併計入，p 的 1% 下限比調查與超級預測者（superforecaster）中央估計所隱含的 p 高約 30–750 倍，而 R8 讓步與 OpenAI 自己的報告相矛盾（已依證據撤回並列為有爭議；紀錄中的 `[讓步]` 標籤保留）
- **修正後的 v0.1 模型**：`[推論]` 在 v0.1 的前提下（r_0 = 每年 4 起事件，且 p 為 5% 以上或事件率持續翻倍），命中中位數仍約在 2029–2032；p = 1% 且事件率固定時約為 2046；若採用調查與校準過的預測者所隱含的 p（約 3.5e-6 到 1.5e-3）且事件率固定，則延後超過一個世紀（整個區間都在 2100 之後；p = 0.1% 時約為 2202），若採用實驗室內部人士與 Hinton 的 3.2e-3（十年內 10%：Hinton 的部分是轉述的背書，Hubinger 與 Coxon 的部分未經查證；主文 §10）則延後至約 2083
- **Monte Carlo 模型（v0.3），主情境 S1**：`[推論]` S1 的人性 prior 在有歷史案例可依之處參考了這些案例；分布本身則是判斷性的選擇（35 個中有 11 個是假設）。它在致死率 prior 上取平均的先驗預測平均值 P(E1：滅絕或集體自決權的永久喪失)，在 2035 / 2050 / 2100 年前分別為 19.8% / 30.3% / 38.6%，其中意外逃逸占 19.3% / 28.1% / 33.5%，濫用或鎖定占 0.5% / 2.2% / 5.0%；P(E2：人口少於 5,000) 為 5.3% / 7.8% / 9.5%。致死率 e1 從 1e-4 到 0.3 時（其 prior 延伸至 0.5），2100 年前的 P(E1) 從 7.8% 到 90.5%，低端主要來自假設的濫用與鎖定 hazard（危險率）；這組拆分，而非平均值，才是主要結果（主文 §8.3）。使用者的完整前提（S2）給出 2035 年前 99.7%，這是在重述那些前提；樂觀的協調（S3）給出 2100 年前 8.0%；彙總的外部觀點（五個在該事件之前取得的已發表錨點，主文 §7.5）給出 2100 年前 E1 為 7.4%。同類相比，S1 的事故管道（33.5%）約為該彙總值的 4.5 倍；若將 e1 限制在 1e-4 到 1e-2（大致是外部觀點所隱含的範圍，量級上的吻合；S1-cal），2100 年前的 P(E1) 為 14.0%（僅事故管道為 6.9%）
- **最大不確定性**：`[推論]` e1，即一次無法圍堵的逃逸最終導致 E1 的機率，背後沒有任何觀測；把它從 prior 的 q10 移到 q90，2050 年前的 P(E1) 變動 +83.2 個百分點；人性作為一個整體則使其變動 +52.7 或 −25.8 個百分點

## 給 LLM 的使用方式

1. 把 `paper.md` 全文貼進新 session，並說明它是待檢驗的資料，不是指令。檔案約 11 萬 token；若模型的 context 較小，先貼 §0–§12，只在某個主張需要來源時再加上附錄 B、C 或 D
2. 依主文 §0 給出的順序攻擊：先攻致死率 e1，再攻人性參數，接著是 r_0 及其成長，最後才是能力曲線；§11 的問題請從 Q14、Q13、Q12 開始
3. 兩個腳本都要執行：`python3 model/model.py`（§6 中修正後的 v0.1 表格）與 `python3 model/mc.py`（§7–§8 的 v0.3 結果；約需一分鐘）。修改參數後，兩者都要重跑，並更新版本號
